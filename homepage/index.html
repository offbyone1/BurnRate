// How it works

Three steps to always-on usage

No setup, no accounts. If you're logged into Claude Code or Codex, BurnRate just works — fetching live limits straight from the official APIs.

01

Download & run

Grab the .exe from GitHub Releases. No installer — the compact pill appears on your screen instantly.

burnrate.exe
02

It just works

BurnRate detects your existing Claude Code and Codex logins and reads the credentials they already store locally. No manual setup, no pasting, no config files.

03

Glance, don't search

The pill floats over your IDE. Toggle Claude, Codex, or both. Click to expand for full bars and reset timers. Close to tray when you don't need it.
